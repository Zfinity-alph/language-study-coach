# Tests and review

Create lesson mock tests only on request, using relevant verified texts and notes. Exclude unclear or missing passages. Prefer a short set of important grammar, reusable structures, government, aspect, and output points over trivia.

For Russian lesson tests, use choice, a coherent contextual cloze, original-order lemma transformation, and both Chinese-to-Russian and Russian-to-Chinese translation when supported. Usually 6–10 items is a useful starting point, not a quota overriding time or scope.

For original-order transformation, separate every token with ，; give inflectable words in dictionary form and keep function words unchanged. Do not require reordering or unlisted content words. Supply enough context to make the desired form recoverable. A lexical aspect counterpart is a different lemma: supply alternatives or an explicit instruction if it must be chosen, rather than disguising it as ordinary inflection.

Put questions before answers. Saved tests may use a folded [!answer]- 答案与解析 callout with complete answers, governing rules and plausible alternatives. In interactive testing, withhold answers until the learner responds unless explicitly requested otherwise. For English tests, adapt question types to the stated goal rather than forcing Russian morphology tasks.

At session review, summarize concepts actually covered and demonstrated errors, provide a compact mini-quiz and teach-back prompt. Distinguish conceptual gaps from slips and follow up on an important weakness. Never invent an error history.

Spaced review dates are proposals, not scheduled events. Save error records or create reminders only with separate authorization and actual available tools. Do not claim a future reminder exists merely because a review plan was written.
