# Russian companion roots

## Confirmed trigger policy

At the first relevant Russian note task, ask whether the user wants companion root notes and follow the decision thereafter. If unset, skipped, or disabled, do not generate them automatically; continue the main task. If the learner profile is blank, this setting does not block note creation. Persist preferences only with authorization.

When enabled, default to at most two distinct source-grounded roots selected by teaching value. The user may change the count or opt into random selection from a verified high-value pool. An explicit current request for a root overrides a general preference. This feature does not automatically create vocabulary master notes.

## Linguistic quality

Choose roots represented in the verified source and valuable for transfer. Verify modern derivation, frequency or productivity claims, affix meanings, and etymology through [research.md](research.md). Distinguish modern word families, historical connections, and spelling look-alikes. Never pad a weak branch to meet a count. If only fewer defensible roots exist, explain the shortfall.

Each branch covers triggering words, semantic core, useful variants and prefix/suffix contrasts, a small practical family, and necessary collocations/examples. Analyze derivatives with the detailed vocabulary fields in [russian-study.md](russian-study.md), rather than listing unexplained words. Mark stress throughout and cite claims near their evidence.

Name paired notes by concise semantic labels, such as 〔意义A〕词根和〔意义B〕词根, unless the user chooses another title. Include source links, genuine branch relations and targeted confusion warnings. Follow [notes.md](notes.md) for output and storage.

## Trigger and update boundaries

Only primary Russian text, dialogue, exercise walkthrough, grammar review, classroom analysis, or explicitly requested vocabulary notes can trigger a companion. Root notes, tests, indexes, profiles, and administrative notes never trigger another companion. A conversational explanation alone does not authorize creating files.

Before creating a companion, inspect the source note's existing links and matching notes. For an update or repeated run, keep previously selected roots and enrich only genuinely new material; do not reselect, duplicate, or rename unless requested. If a root relation is disproven, explain the correction rather than silently preserving it. Same-title notes for different sources require a meaningful qualifier, not overwriting.
